Sobre mí

Explora mi trayectoria profesional, metodología de desarrollo y visión técnica en la construcción de soluciones digitales.

Perfil Profesional

Desarrolladora Web y de Aplicaciones especializada en transformar requerimientos complejos en soluciones digitales de alto impacto. Mi enfoque integra el diseño de interfaces intuitivas y de alta fidelidad visual con una arquitectura de software sólida, garantizando plataformas altamente eficientes, escalables, seguras y centradas en la experiencia de usuario.

Mi objetivo profesional es impulsar la transformación digital de empresas, emprendedores y particulares, desarrollando ecosistemas digitales que no solo proyecten excelencia visual, sino que también optimicen flujos operativos y potencien sus modelos de negocio.

Formación Académica y Capacitación

  • Diplomatura en Desarrollo Web Full Stack

    Institución: Instituto Fundaes (2025 - 2026)

    Formación integral orientada a la ingeniería de software web, abarcando desde la arquitectura de interfaz hasta la gestión de datos y el despliegue de servicios en la nube.

    • Frontend y Experiencia de Usuario: Especialización en maquetación semántica con HTML5, diseño fluido y responsive mediante CSS3, frameworks como Bootstrap y librerías modernas de interfaz. Desarrollo de lógica interactiva en el cliente con JavaScript (ES6+).
    • Backend y Lógica de Servidor: Construcción de servicios web, APIs RESTful y lógica de negocio utilizando Node.js y JavaScript en el entorno del servidor.
    • Bases de Datos (SQL - NoSQL) y Despliegue Cloud: Diseño, modelado y gestión de datos relacionales mediante SQL y no relacionales con MongoDB. Despliegue continuo e integración de infraestructura en la nube con Railway.

  • Carrera de Desarrollo de Aplicaciones Móviles

    Institución: Coderhouse (2026 - En curso)

    Formación en desarrollo de aplicaciones móviles multiplataforma (iOS y Android) enfocado en la creación de soluciones nativas, diseño de interfaces fluidas e integración con servicios cloud.

    • Fundamentos de Programación Mobile y React Native: Aprendizaje en la construcción de interfaces nativas, estructura de componentes y lógica interactiva para dispositivos móviles mediante el uso de React Native y Expo.
    • Navegación y Experiencia de Usuario Móvil: Implementación de flujos de navegación dinámicos (Stack, Tabs) y maquetación adaptable a distintos tamaños de pantalla.
    • Integración de Servicios Cloud y APIs: Conexión con servicios en tiempo real (Firebase), autenticación de usuarios y consumo de datos mediante APIs RESTful.

Stack Tecnológico y Competencias Técnicas

Tecnologías, arquitecturas de software y herramientas aplicadas al desarrollo de soluciones digitales.

1. Desarrollo Web

Ecosistema especializado en soluciones para el navegador, abarcando desde la interfaz visual hasta la lógica del servidor.

A. Frontend Web

Construcción de interfaces interactivas, maquetación adaptable y desarrollo de la lógica del cliente.

HTML5 Semántico

Estructuración limpia, accesible y optimizada para motores de búsqueda (SEO) siguiendo estándares web.

CSS3 (Bootstrap - Flexbox - Grid)

Diseño de maquetaciones modernas, animaciones y componentes adaptables a cualquier tamaño de pantalla.

JavaScript (ES6+)

Desarrollo de interacción en el cliente, manipulación del DOM, programación asíncrona y consumo de servicios web.

B. Backend Web y Bases de Datos

Lógica de negocio, construcción de APIs y gestión de almacenamiento de datos.

JavaScript - Node.js - Express

Creación de servidores web, gestión de rutas y desarrollo de APIs RESTful eficientes.

MongoDB (NoSQL)

Modelado y gestión de bases de datos no relacionales orientadas a documentos flexibles.

SQL (Bases de Datos Relacionales)

Diseño de esquemas, consultas estructuradas y organización de datos con integridad relacional.

2. Desarrollo de Aplicaciones Móviles

Soluciones multiplataforma para entornos móviles, enfocado en el rendimiento y la fluidez operativa.

A. Frontend Mobile

Estructuración de pantallas nativas y experiencia de usuario táctil.

JavaScript - JSX (React Native / Expo)

Creación de interfaces nativas para iOS y Android con componentes reutilizables y flujos de navegación fluidos.

B. Backend Mobile y Servicios Cloud

Servicios de sincronización y almacenamiento en la nube para aplicaciones móviles.

Firebase (Realtime DB - Authentication)

Integración de autenticación de usuarios, bases de datos en tiempo real y almacenamiento en la nube.

Integración de APIs RESTful

Conexión asíncrona entre la aplicación móvil y servidores externos para el consumo de datos en tiempo real.

3. Diseño de Interfaces y Experiencia de Usuario (UI/UX)

Prototipado visual y maquetación conceptual previa a la fase de programación.

Figma

Diseño de wireframes, prototipos interactivos web y móviles, y creación de componentes visuales de interfaz.

4. Herramientas Colaborativas y Despliegue

Gestión del código fuente, trabajo en equipo e infraestructura de servidores.

Git - GitHub

Control de versiones distribuido, administración de repositorios y flujos de trabajo colaborativos.

Railway (Cloud Infrastructure)

Despliegue de aplicaciones backend en Node.js y conexión con bases de datos en producción.

Pilares de Trabajo y Filosofía Profesional

Principios rectores que garantizan la excelencia técnica, la eficiencia operativa y el éxito en cada proyecto.

  • Arquitectura Robusta y Escalable

    Diseño e implementación de soluciones digitales orientadas a la mantenibilidad y al crecimiento progresivo a largo plazo, garantizando un rendimiento óptimo, código estructurado y altos estándares de seguridad.

  • Diseño Centrado en el Usuario (UX/UI)

    Priorización de la usabilidad, la accesibilidad y la jerarquía visual para asegurar interacciones fluidas, intuitivas y eficientes en cualquier dispositivo y plataforma.

  • Cumplimiento Metódico de Plazos (Entregas a Tiempo)

    Gestión rigurosa del tiempo y planificación por hitos, asegurando la entrega puntual de cada fase del proyecto sin comprometer la calidad ni los estándares técnicos acordados.

  • Calidad de Código y Buenas Prácticas

    Desarrollo fundamentado en estándares modernos de la industria, aplicando patrones de diseño, código limpio (Clean Code) y optimización continua de recursos.

  • Alineación Estratégica y Comunicación Transparente

    Colaboración estrecha para traducir requerimientos operativos en especificaciones técnicas precisas, brindando un acompañamiento constante y asesoramiento claro durante todo el ciclo de desarrollo.
